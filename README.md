# Password Manager

Простой менеджер паролей с графическим интерфейсом на **Python и PyQt6**. Приложение хранит учётные данные в локальной базе SQLite, защищает пароли шифрованием и позволяет организовывать записи по категориям.

## Возможности

- Создание мастер-пароля и вход в хранилище.
- Шифрование сохранённых паролей с помощью Fernet.
- Хеширование мастер-пароля с помощью bcrypt.
- Получение ключа шифрования из мастер-пароля с использованием PBKDF2-HMAC-SHA256.
- Добавление, редактирование и удаление записей.
- Категории и список избранного.
- Поиск по названию сервиса, логину и заметкам.
- Генерация паролей и оценка их надёжности.
- Копирование пароля в буфер обмена.
- Импорт и экспорт записей в CSV.

## Технологии

- **Python** — язык программирования.
- **PyQt6** — графический интерфейс.
- **SQLite** — локальная база данных.
- **bcrypt** — хеширование мастер-пароля.
- **cryptography (Fernet, PBKDF2HMAC)** — шифрование данных и получение ключа.

Точные версии установленных зависимостей указаны в `requirements.txt`.

## Установка и запуск

Для запуска нужен установленный Python.

1. Склонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone https://github.com/andrei27062010-blip/password-manager-pyqt.git
   cd password-manager-pyqt
   ```

2. (Рекомендуется) создайте виртуальное окружение:

   **Windows:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

   **Linux / macOS:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Запустите приложение:

   ```bash
   python main.py
   ```

При первом запуске приложение предложит создать мастер-пароль. База данных SQLite и файл конфигурации мастер-пароля создаются приложением автоматически.

## Хранение и защита данных

- Пароли записей хранятся в базе данных в зашифрованном виде.
- Для шифрования используется Fernet из библиотеки `cryptography`.
- Ключ шифрования получается из мастер-пароля с помощью PBKDF2-HMAC-SHA256.
- Для проверки мастер-пароля используется bcrypt.

**Важно:** не забывайте мастер-пароль. Также не передавайте другим файл базы данных и файл конфигурации. Экспорт в CSV предназначен для переноса данных: такой файл содержит пароли в открытом виде, поэтому храните его безопасно и удаляйте, когда он больше не нужен.

## Импорт и экспорт

Приложение поддерживает CSV-файлы. Импорт распознаёт распространённые названия столбцов, в том числе формат Google Password Manager. При экспорте создаётся CSV с данными записей, категориями и отметками избранного.
